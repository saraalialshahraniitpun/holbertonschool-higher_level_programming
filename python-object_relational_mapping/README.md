# Python - Object-relational mapping

This project introduces the connection between Python and MySQL databases using MySQLdb and SQLAlchemy ORM.
- **0-select_states.py**: Python script that lists all states from a MySQL database using MySQLdb.
- **1-filter_states.py**: Python script that lists all states with a name starting with N (upper N) from a MySQL database.
- **2-my_filter_states.py**: Python script that takes an argument and displays all values in the states table where name matches the argument using exact comparison.
