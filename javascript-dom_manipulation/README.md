# JavaScript - DOM manipulation

This project focuses on manipulating the Document Object Model (DOM) using JavaScript, handling user events, and fetching data from APIs asynchronously.

## Resources
* [DOM (Document Object Model)](https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model)
* [Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API)
* [Semistandard Style](https://github.com/standard/semistandard)

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`
* Interpreted on Chrome browser (version 57.0 or later)
* All files should end with a new line
* Code should be semistandard compliant
* You are not allowed to use `var`
* HTML should not reload for each action (DOM manipulation, updating values, fetching data)

## Tasks

| Task | File | Description |
|---|---|---|
| 0. Color Me | `0-script.js` | Updates the text color of the header element to red. |
| 1. Click and turn red | `1-script.js` | Changes header text color to red on click. |
| 2. Add .red class | `2-script.js` | Adds the `.red` class to the header on click. |
| 3. Toggle classes | `3-script.js` | Toggles between `.red` and `.green` classes on the header. |
| 4. List of elements | `4-script.js` | Appends a new `<li>Item</li>` to a list on click. |
| 5. Change the text | `5-script.js` | Updates header text to "New Header!!!" on click. |
| 6. Star wars character | `6-script.js` | Fetches and displays a Star Wars character's name. |
| 7. Star Wars movies | `7-script.js` | Fetches and lists all Star Wars movie titles. |
| 8. Say Hello! | `8-script.js` | Fetches a translation of "hello" in French from an API. |
