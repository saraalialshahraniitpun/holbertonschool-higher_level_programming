# JavaScript - Warm up

This project is an introduction to JavaScript programming using Node.js, covering basic syntax, variables, conditions, loops, and command-line arguments while adhering to Semistandard style guidelines.

## Resources
* [Node.js Documentation](https://nodejs.org/en/docs/)
* [Semistandard Style](https://github.com/standard/semistandard)
* [JavaScript Overview - MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`
* All files interpreted on Ubuntu 20.04 LTS using `node` (version 14.x)
* All files should end with a new line
* The first line of all files should be exactly `#!/usr/bin/node`
* Code should be semistandard compliant (`version 16.x.x`)
* All files must be executable

## Tasks

| Task | File | Description |
|---|---|---|
| 0. First constant, first print | `0-javascript_is_amazing.js` | Prints "JavaScript is amazing" using a constant variable. |
| 1. 3 languages | `1-multi_languages.js` | Prints 3 specific lines for C, Python, and JavaScript. |
| 2. Arguments | `2-arguments.js` | Prints a message depending on the number of arguments passed. |
| 3. Value of my argument | `3-value_argument.js` | Prints the first argument passed to the script. |
| 4. Create a sentence | `4-concat.js` | Prints two arguments in the format "a is b". |
| 5. An Integer | `5-to_integer.js` | Converts the first argument to an integer or prints "Not a number". |
| 6. Loop to languages | `6-multi_languages_loop.js` | Prints 3 languages using an array and a loop without `if/else`. |
