# Python - Server Side Rendering

This project covers server-side rendering concepts using Python, string templating, and the Flask web framework with Jinja templating engines.

## Resources
* [Python Official Documentation](https://docs.python.org/)
* [Flask Quickstart](https://flask.palletsprojects.com/en/2.0.x/quickstart/)
* [Jinja Template Designer Documentation](https://jinja.palletsprojects.com/en/3.0.x/templates/)

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`
* All files interpreted/compiled on Ubuntu 20.04 LTS using Python 3
* All files should end with a new line
* A mandatory `README.md` file at the root of the project folder

## Tasks

| Task | File | Description |
|---|---|---|
| 0. Simple Templating Program | `task_00_intro.py`, `template.txt` | Generates personalized invitation files from a template and structured attendee data with error handling. |
| 1. Basic HTML Template in Flask | `task_01_jinja.py`, templates | Sets up a basic Flask application utilizing Jinja layouts, reusable headers, and footers. |
| 2. Dynamic Template with Loops and Conditions | `task_02_logic.py`, `items.json`, `items.html` | Renders dynamic content from a JSON data source using loops and conditional logic in Flask templates. |
